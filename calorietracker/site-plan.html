Calorie Tracker – Site Plan

Edward Kane

WDD 131-A1

Overview

Purpose

The purpose of the Calorie Tracker App is to help users track their daily meals, estimate calorie intake, and receive simple nutrition guidance. This app keeps healthy eating easy, fast, and consistent without needing a full nutrition tracking app. It supports users in making better meal decisions that match their fitness and lifestyle goals.

Audience

This site is designed for individuals who want to improve their eating habits, track calories, and maintain healthier routines. The audience includes busy students, athletes, working adults, and basically anyone who wants a simple and clean tool to monitor their meals without complicated features.

Dynamic elements

The site will use Javascript to provide several dynamic features. Users will add meals through a form, creating meal objects stored in an array and saved to localStorage. Javascript will render added meals dynamically to the Meals page and calculate daily calorie totals. Meal filtering (breakfast, lunch, dinner, snacks, calorie ranges) will update the display instantly. A random nutrition tip generator will pull from a list of preset tips using Math.random(). ES modules will be used to organize code across multiple files, and event listeners will handle form submissions, button clicks, and DOM updates.

Content

Home page

The home page will introduce the Simple Meal & Calorie Coach App and explain how users can track their meals. It will display today's calorie total, two navigation buttons (Add Meal and View Meals), and a box that shows a random nutrition tip.

Meals Page

The Meals page will show all meals the user has entered. Each meal will appear as a styled card with the meal name, category, and calorie amount. Users will be able to filter meals by category or calorie range using dynamic buttons. A summary section will show daily calorie totals and meal statistics.
